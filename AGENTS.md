# Working on OpenClaw Workspace

OpenClaw owns the main conversation. Ollama runs local inference. OpenCode is the optional ACP coding backend. Use README.md for current operation. Treat legacy/jarvis-os as archived material.

Keep changes independent of a particular Windows username or isolated account. Use supported OpenClaw commands for live checks. Keep device identifiers, credentials, saved profiles, model weights and chat histories out of commits. Changes to the status tool should preserve its read-only behavior and nonzero exit on failure.
